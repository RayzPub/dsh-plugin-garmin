#### 3. 攻坚消除的核心根因与代码改动

1. **解决代码与预览脱节（Visual Fidelity 严重缺失）**：
   - **根因**：`src/preview/code-generator.ts` 此前对所有微件粗暴使用单行 `dc.drawText(...)` 降级，导致生成的 Monkey C 无法呈现矢量预览中的进度弧和电量条。
   - **修复**：在代码生成引擎中注入零分配线段弧辅助方法 `drawArcRing()`，为 `heart_rate` 与 `steps` 生成动态进度弧代码，为 `battery` 生成 `fillRectangle` 比例填充矩形，为 `date` 生成带背景和边框的视窗。
2. **根除 `onUpdate()` 堆内存分配（Zero Allocation 门禁违规）**：
   - **根因**：刻度数字生成器中存在硬编码 `var hours = [12, 3, 6, 9];`，导致每秒渲染循环均在堆上分配数组字面量。
   - **修复**：重构为算术推导循环 `for (var h = 0; h < 4; h += 1) { var val = (h == 0) ? 12 : (h * 3); ... }`，实现 100% 零分配。
3. **修复 Manifest XSD 与按需权限控制**：
   - **根因**：缺少必须的 `<iq:languages>` 节点；且包含高度计微件时缺少权限声明。
   - **修复**：在 `src/tools/garmin-scaffold.ts` 中默认生成标准语言节点，并依据微件实际需求动态注入 `<iq:uses-permission id="SensorHistory"/>`。
4. **增强参数别名容错**：
   - **根因**：工具说明显示 `battery`，但内部模型校验为 `batteryPercent`。
   - **修复**：在 `src/tools/garmin-preview.ts` 中加入智能别名归一化。
